LuauGBA - ROM embedding tool

Runs entirely in your browser. The ROM is never uploaded anywhere.

1. Choose a ROM

drop a .gba file here, or click to choose

2. Generate the module

3. Install it

  1. Save the download as src/Assets/ROM.luau in the LuauGBA repo.
  2. Make sure default.project.json maps src/Assets to ReplicatedStorage.Assets.
  3. Run rojo serve, connect in Studio, press Play. The client auto-loads it.
Do not commit ROM.luau to git - it is already in .gitignore.
