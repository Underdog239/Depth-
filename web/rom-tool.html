LuauGBA - ROM helper

Runs entirely in your browser. The ROM is never uploaded anywhere.

1. Choose a ROM

drop a .gba file here, or click to choose

2. Generate the module

3. Install it

  1. Small ROM: Generate, Copy base64, then open Depth's Menu → Add a game → Load pasted ROM.
  2. Larger ROM in your own Studio place: Download Studio ROM installer. Stop Play, open the downloaded text file, and paste it into Studio's Command Bar. Press Play: the ROM loads automatically.
  3. If replacing a game, export its battery save first. In Edit mode remove only your old ReplicatedStorage.Assets.ROM, then run the new ROM installer.
  4. Rojo users: Download ROM module as src/Assets/ROM.luau, then rebuild/sync.
Do not commit ROM.luau to git - it is already in .gitignore.
